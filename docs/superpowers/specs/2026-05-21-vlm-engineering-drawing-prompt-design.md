# VLM 工程图读取提示词优化 — 设计规格

**日期：** 2026-05-21  
**文件：** `backend/pipeline/vlm_feature.py`  
**范围：** 仅改写 `_VLM_ENGINEERING_DRAWING_PROMPT` 中两个字段的指令；不改其他函数或处理逻辑。

---

## 问题

`extract_creo_primary_features` 调用 VLM 时使用 `_VLM_ENGINEERING_DRAWING_PROMPT`，当前有两个字段识别质量差：

1. **外形尺寸** — 每张二维工程图只显示两个轴（主视图→长×高，左/俯视图→宽/厚方向），VLM 不清楚视图类型与轴向的对应关系，导致无法正确合并为唯一最大外轮廓值。
2. **尺寸公差 / 形位公差** — 实际图纸上有公差标注，但 VLM 频繁返回"无"，原因是提示词没有明确指出要扫描的符号类型和位置。

---

## 目标

- `【外形尺寸】`：VLM 输出单个综合最大外轮廓，格式 `长×宽×厚`（而非多视图分别列出）。
- `【尺寸公差】【形位公差】`：VLM 能可靠识别公差框格、数字旁公差、标题栏未注公差，减少误报"无"。

---

## 不在范围内

- 不修改 `_apply_drawing_size_reference_to_lwh`（保留为 fallback 校正）。
- 不修改其他字段的提示词（通孔、螺纹孔、表面处理等）。
- 不引入两轮 VLM 调用。
- 不修改测试文件（除非现有测试因提示词文本检查而需同步更新）。

---

## 设计

### 修改 1 — `【外形尺寸】` 指令

**改前：**
```
【外形尺寸】综合多视图中明确标注的外轮廓尺寸，按长×宽×厚/高输出；只抄图纸数字，不估算；
厚度取最薄方向整体通长尺寸，不取槽深/台阶高/局部特征深度
```

**改后：**
```
【外形尺寸】
第一步：识别每张图的视图类型（主视图/左视图/右视图/俯视图/剖视图/其他）
第二步：按视图类型提取轴向尺寸
  - 主视图 → 长方向和高方向的最大外轮廓标注值
  - 左视图/右视图 → 宽（厚度）方向和高方向的最大外轮廓标注值
  - 俯视图 → 长方向和宽方向的最大外轮廓标注值
第三步：取各方向最大整体外轮廓值，合并输出一个值，格式：长×宽×厚
规则：厚度取最薄方向整体通长尺寸，不取槽深/台阶高/局部特征深度；只抄图纸数字，不估算
```

**意图：** 通过三步链式推理引导 VLM 先分解视图、再识别轴向、最后合并，避免跨视图混淆。

---

### 修改 2 — `【尺寸公差】【形位公差】` 指令

**改前：**
```
【尺寸公差】所有带公差标注的尺寸和未注尺寸公差说明
【形位公差】平面度、垂直度、位置度、圆柱度等
```

**改后：**
```
【尺寸公差】逐张扫描以下位置：
  ① 每个尺寸数字旁的公差符号（如 ±0.05、+0.02/-0.01、H7、h6、JS6）
  ② 标题栏或技术要求区的"未注公差"说明（如"未注公差按GB/T 1804-m"）
  ③ 公差框格内的极限偏差数值
  格式：尺寸值 公差；未注公差说明；如确实无任何公差标注则填"无"
【形位公差】逐张扫描公差框格（矩形框+箭头引线），提取：类型符号（平面度/垂直度/位置度等）、
  公差值、基准代号；如确实无形位公差标注则填"无"
```

**意图：** 明确列出三类扫描目标和位置，让 VLM 不遗漏公差符号；将"无"设为最后的退路而非默认。

## 风险

- VLM 能力限制：提示词改进有助于引导，但无法保证所有零件都完美识别。
- `_apply_drawing_size_reference_to_lwh` 的后处理逻辑假设 VLM 可能输出多视图格式（`|` 分隔）；改后 VLM 若直接输出单值，后处理中的分组解析依然兼容（单值会作为一个 group 处理）。
