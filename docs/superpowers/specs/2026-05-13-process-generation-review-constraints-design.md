# 工艺生成以审阅特征为主约束 + 低相似度受控替换 — 设计文档

> **日期**: 2026-05-13

---

## 1. 目标

将当前零件的**审阅特征表**提升为工艺生成的**主约束源**，防止工艺蓝本或低相似度候选将当前零件的核心几何尺寸带偏。

具体目标：

1. **图号精确匹配 + 相似度 ≥ 70%** 时，蓝本工艺仍可作为主流程框架，但若蓝本中的核心尺寸与当前审阅特征冲突，必须以当前特征为准。
2. **图号不匹配或相似度 < 70%** 时，蓝本只能作为流程参考，不允许覆盖当前零件的毛坯尺寸、外形尺寸和关键尺寸。
3. 低相似度下允许从历史相似特征中补充有限范围的数值类内容，但仅限于受控字段，不允许自由推演主体几何尺寸。

---

## 2. 范围

### 做

- `backend/pipeline/process_gen.py`：新增“约束装配器”逻辑，调整 prompt 构造与检索结果使用方式
- 工艺生成前增加当前审阅特征的结构化提取
- 对低相似度候选增加“局部特征补充”逻辑
- 工艺生成后增加轻量冲突校验（post-check）

### 不做

- 不修改 `backend/pipeline/vlm_feature.py` 的 12 字段结构
- 不修改前端审阅表 UI
- 不修改蓝本存储结构与知识库 schema
- 不重做整条 RAG 链路，只在 `process_gen.py` 内部增加约束层

---

## 3. 核心原则

### 3.1 审阅特征优先级最高

当前零件的 `review_text` / `feature_text` 是工艺生成的主事实源。只要某项特征在当前审阅表中已明确给出，就不能被历史蓝本或低相似度候选覆盖。

### 3.2 蓝本用于“框架”，不是用于“改写当前事实”

蓝本的价值在于：
- 工序顺序
- 标准表达
- 常见工艺步骤组合

蓝本不能改变当前零件的核心几何事实。

### 3.3 低相似度只允许“局部受控替换”

当图号不匹配或相似度 < 70% 时，只能从历史相似特征中补有限范围的数值类内容，不能整段照搬工艺，也不能对主体尺寸做按比例推演。

---

## 4. 字段边界

### 4.1 硬约束字段（禁止历史覆盖）

以下字段只能来自**当前审阅特征表**或由当前特征直接推导：

- 毛坯尺寸
- 外形尺寸
- 关键尺寸
- 当前零件明确给出的主孔位数量 / 主轮廓尺寸
- 任何会改变零件主体几何的尺寸

如果蓝本或历史候选中出现不同值：
- 不允许沿用
- 不允许让 LLM 自行折中
- 不允许按比例估算后覆盖当前值

### 4.2 允许补充字段（低相似度可受控替换）

当 **图号不匹配或相似度 < 70%** 时，只允许从历史相似特征中补以下字段：

- 粗糙度
- 倒角
- 圆角
- 表面处理参数
- 孔径
- 螺纹规格
- 孔深

补充条件必须同时满足：

1. **当前审阅特征没有明确值**
   - 若当前特征已给出，则禁止历史覆盖
2. **历史候选的局部特征确实相似**
   - 不是整件整体相似，而是该类特征本身有匹配依据

### 4.3 明确禁止补充的内容

即使历史候选很像，也不允许补：

- 毛坯厚度 / 长宽 / 外形包络
- 总体外轮廓尺寸
- 与主体结构绑定的关键尺寸
- 当前审阅特征已明确但历史值不同的数值

## 5. 架构

### 5.1 数据流

```text
review_text / fused_description
    + RAG 检索结果
    ↓
Constraint Assembler   ← 新增
    ├─ 提取硬约束字段
    ├─ 判断 exact match / similarity >= 70
    ├─ 判断哪些字段允许历史补充
    └─ 组装给 LLM 的受控上下文
    ↓
LLM 生成工艺
    ↓
Post-check（轻量冲突校验）
```

### 5.2 三类输入源

#### A. 当前审阅特征（最高优先级）

来自 `review_text`，提供：
- 毛坯尺寸 / 外形尺寸 / 关键尺寸
- 当前零件孔特征、螺纹、倒角、表面处理等

这是工艺生成的主事实源。

#### B. 蓝本工艺

来自现有 RAG 命中的工艺候选，提供：
- 工序顺序
- 标准表述
- 成熟流程框架

但不能覆盖硬约束。

#### C. 历史相似特征片段

当 **图号不匹配或相似度 < 70%** 时启用，仅提取允许补充的局部内容：
- 粗糙度
- 倒角 / 圆角
- 表面处理
- 孔径 / 螺纹规格 / 孔深

不是整段历史工艺替换，而是局部补料。

## 6. `process_gen.py` 设计改动

### 6.1 `_extract_process_constraints(review_text: str) -> dict`

从当前审阅特征表提取结构化约束：

```python
{
  "hard_constraints": {
    "blank_size": "...",
    "outer_size": "...",
    "key_dims": "..."
  },
  "soft_features": {
    "roughness": "...",
    "chamfer": "...",
    "fillet": "...",
    "surface_treatment": "...",
    "holes_threads": "..."
  }
}
```

说明：
- `blank_size`：优先从当前特征中明确毛坯表达提取；若不存在，则留空，不允许历史直接补毛坯尺寸
- `outer_size`：来自当前零件外形尺寸表达
- `key_dims`：来自 `【关键尺寸】`
- `holes_threads`：来自孔径、螺纹规格、孔深等可受控补充项

### 6.2 `_should_use_blueprint_as_base(exact_match: bool, similarity: float) -> bool`

规则：
- 精确图号 + 相似度 ≥ 0.70 → 蓝本可作为主框架
- 其他情况 → 蓝本只能作为参考框架，不得作为主事实源

### 6.3 `_extract_allowed_feature_fragments(rag_context: str, review_constraints: dict) -> dict`

从历史候选中提取允许补充的局部特征，只返回受控字段：

```python
{
  "roughness": "Ra3.2",
  "chamfer": "锐边倒钝",
  "fillet": "R0.5",
  "surface_treatment": "导电阳极化",
  "holes_threads": "M3 深6，底孔φ2.5深7"
}
```

过滤规则：
- 当前审阅特征已明确的字段，不允许历史覆盖
- 若候选上下文只提供整段工艺、无法定位到具体允许字段，则不采用

### 6.4 `_build_controlled_prompt(...)`

替代当前较宽松的 prompt，新增明确约束：

1. 当前审阅特征是最高优先级
2. 毛坯尺寸 / 外形尺寸 / 关键尺寸绝不可被蓝本或历史候选覆盖
3. 当图号不匹配或相似度 < 70% 时，只允许借用指定字段：
   - 粗糙度
   - 倒角 / 圆角
   - 表面处理
   - 孔径 / 螺纹规格 / 孔深
4. 不得根据蓝本按比例推演主体几何尺寸
5. 若当前特征未提供某项信息且历史候选也无可靠局部命中，则保持中性，不补数值

## 7. 生成策略

### 7.1 精确图号命中 + 相似度 ≥ 70%

- 蓝本工艺作为主框架
- 仍需用当前审阅特征校正冲突项
- 蓝本中的流程和表述可大体保留
- 若 `0010 备料`、外形尺寸、关键尺寸与当前特征冲突，必须改成当前特征值或中性表述

### 7.2 图号不匹配 / 相似度 < 70%

- 蓝本只提供流程参考，不提供事实覆盖
- 当前审阅特征作为工艺内容主依据
- 历史相似特征片段只允许补你批准的可替换字段
- 不允许沿用蓝本毛坯尺寸，不允许按比例生成主体尺寸

---

## 8. 后处理校验（Post-check）

在 LLM 返回文本后，增加轻量校验：

### 检查对象
- `0010` 备料工序
- 外形尺寸表达
- 关键尺寸表达
- 主孔位数量/主轮廓数值

### 校验规则
- 若输出值与 `hard_constraints` 冲突：
  1. 优先替换为当前硬约束值
  2. 若无法安全替换，则删除冲突数值，仅保留中性工艺描述

### 示例
- 错误：`0010@备料：δ30×380×376.5=1`
- 当前硬约束：`δ20×390×248=1`
- post-check 后：
  - 若能明确映射 → `0010@备料：δ20×390×248=1`
  - 若当前特征不足 → `0010@备料：按当前零件外形尺寸备料。`

---

## 9. 错误处理与降级

### 情况 A：审阅特征缺少关键尺寸

- 不允许蓝本直接补毛坯尺寸
- 标记为“当前特征不足”
- LLM 只能生成保守工艺，不得写冲突主体尺寸

### 情况 B：低相似度且局部特征也检索不到

- 不补数值
- 仅保留通用非数值语句，例如：
  - 锐边倒钝
  - 去毛刺
  - 清洗
  - 检验
  - 标识

### 情况 C：蓝本与当前特征冲突

- 当前审阅特征优先
- 蓝本仅保留不冲突部分

### 情况 D：LLM 仍生成了禁止替换项

- post-check 拦截
- 用当前硬约束值覆盖，或删掉冲突数值改为中性表述

### 集成测试

1. **高相似度蓝本复用**
   - 图号命中 + ≥70%，流程保留，冲突尺寸被纠正

2. **低相似度受控替换**
   - 不匹配 / <70%，主体尺寸不被蓝本覆盖，允许补孔/螺纹/粗糙度等

3. **无可靠候选**
   - 不补危险数值，仅保留中性工艺步骤

## 12. 预期效果

实施后，系统行为应从：

- 蓝本主导 + 当前特征辅助参考

变为：

- 当前审阅特征主导 + 蓝本提供框架 + 低相似度下仅局部受控补充

核心收益：

1. 避免 `0010 备料` 被蓝本尺寸带偏
2. 避免主体几何尺寸被 LLM 按比例推演
3. 保留蓝本在流程组织与标准表达上的价值
4. 在低相似度场景下仍能复用通用工艺经验，而不是完全从零生成
