# Auth Entry Mimo Overlay Design

## Goal

将当前登录页重构为一个更接近 `mimo.mi.com` 的极简产品入口页：

- 默认首页保持安静、稀疏、可呼吸
- 登录/注册表单不预先常驻页面中央
- 点击右上角“进入系统”后，主视觉中的地球/连线区域淡出
- 登录面板以平滑、舒适的方式淡入
- 用户随后可执行登录、注册等操作

这个页面不再是传统的“双栏登录页”，而是“产品首页 + 按需展开的认证层”。

## Accepted Direction

### Layout

- 页面默认状态采用接近 MiMo 的结构骨架：
  - 浅暖白背景
  - 顶部极简导航
  - 左侧单组大标题文案
  - 右侧一个低信息密度的地球/轨道主视觉
  - 右上角主 CTA：`进入系统`
- 默认状态不展示输入框、不展示登录卡、不展示说明型辅助卡片

### Interaction Model

页面有两个主状态：

1. `home`
   - 地球主视觉可见
   - 认证表单隐藏
   - 右上角 CTA 可触发进入认证流程

2. `auth`
   - 触发后，地球主视觉淡出或弱化
   - 认证面板淡入
   - 用户可切换登录/注册
   - 页面仍保留首页的极简外壳，不切换到另一套完全不同的布局

状态切换原则：

- 不能突兀跳变
- 不能像弹窗广告
- 应更像同一页面内部的状态流转

### Motion

动效参考 MiMo 的安静产品化表达，不做炫技：

- CTA 点击后：
  - 地球区域 `opacity` 降低，并可配合轻微 `scale` / `blur`
  - 登录面板 `opacity` 提升，并有轻微位移进入
- 整体节奏应偏慢一点点，但不能拖沓
- 建议过渡时长：
  - 主状态切换：`320ms - 480ms`
  - Hover / focus：`160ms - 220ms`
- 动效曲线以柔和 ease-out 为主
- 必须支持 reduced motion

### Interaction Principles

这次实现必须“学其神”，不是只学页面外形。需要吸收的是 MiMo 当前页面的交互组织方式：

- 默认状态尽量少说话，不急于把所有功能摊开
- 主 CTA 是一个状态触发器，不只是一个普通按钮
- 页面切换更像同一场景内的状态流转，而不是跳转到另一张完全不同的页面
- 视觉主元素需要在触发后让位给操作层，而不是继续和表单争抢注意力
- Hover、focus、loading、dismiss 都要有轻但明确的反馈
- 所有反馈都应服务于“用户接下来要做什么”，而不是为了装饰页面

实现时要重点学习并转译这些交互特征：

- 导航与 CTA 的克制悬停反馈
- 主视觉在状态切换时的退场逻辑
- 表单层进入时的节奏、透明度、位移和层级关系
- 页面在 `home -> auth -> home` 之间往返时是否依然稳定、安静、流畅

禁止只做以下浅层模仿：

- 只抄白底黑字排版
- 只抄右侧地球图形
- 只抄按钮位置
- 用更复杂的内容破坏 MiMo 式的信息克制

### Visual Language

- 配色尽量贴近 MiMo 当前页面：
  - 浅暖白背景
  - 黑色/近黑标题与导航
  - 低对比灰色辅助信息
  - CTA 允许保留项目品牌色，但需要先做一版接近 MiMo 的黑色按钮方案进行验证
- 内容密度严格克制
- 避免任何不必要的卡片、状态条、装饰说明区
- 阴影极轻
- 圆角统一，但不夸张
- 登录层应更像“页面状态层”，而不是独立营销卡片

### Auth Surface

认证层需要支持：

- 登录
- 注册
- 用户名 / 密码输入
- 密码可见性切换
- 错误提示
- 提交中状态
- 从登录切换注册
- 从认证层返回首页主状态

认证层默认优先保证：

- 可读性
- 操作顺序清晰
- 状态反馈明确

而不是强调视觉装饰。

## Implementation Boundaries

- 本轮只重构认证入口页及其动画/状态切换
- 不改变认证业务逻辑
- 尽量复用现有登录/注册逻辑与上下文
- 可以重构认证页组件结构，使其适配 `home/auth` 双状态模型

## Risks To Watch

- 做得太像 marketing landing page，失去系统入口感
- 登录层过重，破坏首页的空白感
- 动效过强，抢掉操作本身
- 登录与注册切换如果仍像旧双栏页面，会再次产生风格断裂

## Success Criteria

实现后应满足：

- 默认第一屏更接近 MiMo 的简洁感
- 用户不会先看到传统居中登录卡
- 点击“进入系统”后能明显感知页面进入认证状态
- 登录/注册面板与首页属于同一套视觉系统
- 页面整体比现有版本更简洁、更安静、更统一
