# 厚度区间博弈中位数修正

## 问题

`_anchor_occ_lwh_to_creo` 中 OCC BoundBox X 轴在竖放模型上抓不到真正的 长，匹配失败后原值保留。
触发 `min > 50 → 50` cap 后，厚度值仅为粗暴的 50mm，不是真实材料厚度。

## 方案

cap 触发后用 Creo 特征尺寸(2-50mm 区间带 `× N` 的值)做区间博弈中位数计算，
替换被 cap 的最小维度值。

## 算法(纯 Python，不调 LLM)

### Step 1 — 清洗分组
- 剥离 `× N` 得核心数值，去重
- 按整十数分组 [0,10), [10,20), [20,30)...
- 统计每区间独立数值个数

### Step 2 — 博弈选区间(优先级从上到下)
1. Fallbacknet: 10以上全空且[0,10)有值 → [0,10)
2. 数量篡位: ≥10区间有≥10个独立值 → 该区间(多个取最低)
3. 常规压制: 从高到低扫描，首个≥5 → 锁定
4. 残局暴动: 纯数量PK，最多者胜，平局高位优先

### Step 3 — 升序排列锁定区间内所有值

### Step 4 — 取中位数，奇数取中间，偶数取两中间均值
