# 二维工艺系统 — PPT 内容稿

## P1 — 封面

**主标题：** 二维工艺系统

**副标题：** 基于 2D 工艺图纸的 AI 智能工艺规程生成系统

**底部信息：** 2026 年 6 月

---

## P2 — 项目背景

### 行业痛点

- 传统工艺规程编写依赖人工经验，效率低、周期长
- 2D 图纸特征提取（尺寸公差、粗糙度、形位公差）纯靠手工，易遗漏
- 工艺知识分散在个人经验和 Excel 表格中，难以复用和传承
- 同类零件重复编写工艺规程，浪费大量工时

### 系统定位

> 用 AI 替代重复劳动，让工艺工程师聚焦核心判断

- **输入：** 2D 工艺图纸（PDF/PNG/JPG）或 3D 模型（PRT）
- **输出：** 结构化工艺规程（工序号、工种、工序内容）
- **核心能力：** VLM 视觉特征提取 + RAG 知识库检索增强生成

---

## P3 — 系统概述

### 核心业务流程

```
上传图纸/模型 → AI 特征提取 → 人工审阅确认 → 工艺规程生成 → 导出/入库
```

### 系统价值

| 维度 | 传统方式 | 智能系统 |
|------|----------|----------|
| 特征提取 | 人工逐项标注，30-60min | AI 自动提取，2-5min |
| 工艺编写 | 参考手册手写，1-2h | RAG 检索 + LLM 生成，5-10min |
| 知识复用 | 依赖个人经验 | 知识库统一管理，跨人员共享 |
| 质量一致性 | 因人而异 | 标准化模板 + AI 辅助 |

## P4 — 技术架构

### 技术栈

| 层次 | 技术 |
|------|------|
| 前端 | HTML5 + CSS3 + 原生 JavaScript |
| 3D 预览 | Three.js + GLTFLoader |
| 标注工具 | 自研 SVG BoundingBox 标注模块 |
| PDF 导出 | Vue 3 + jsPDF + OPPOSans 中文字体 |
| 后端通信 | Fetch API + SSE（Server-Sent Events） |
| 后端 | Python Flask + SQLite |
| AI 能力 | VLM 视觉语言模型 + RAG 检索增强生成 |

### 架构特点

- **单页应用：** 侧栏导航 + 页面切换，无刷新跳转
- **流式通信：** SSE 长连接实时推送进度和工艺输出
- **打字机动画：** 逐行逐字符输出工艺规程，模拟真人编写
- **多知识库隔离：** 公共库（只读）+ 用户私有库（可编辑）

## P6 — 工艺入库

### 功能说明

通过上传 ZIP 工艺包，批量将工艺知识导入系统数据库。

### 核心特性

- **入库目标：** 支持选择已有库或新建私有工艺库
- **冲突模式：** 替换入库 / 保留旧版
- **实时进度：** 空闲 → 上传中 → 解析中 → 入库中 → 完成
- **结果展示：** 已匹配记录、未匹配项、批次日志三个 Tab

### 流程

```
选择 ZIP 文件 → 选择目标库和冲突模式 → 开始导入
→ 系统解析 ZIP 内容 → 匹配图纸与工艺文件
→ 逐条入库 → 显示匹配结果和日志
```

> **截图位置：** 插入工艺入库成功截图（显示匹配结果和进度完成状态）

## P7 — 工艺生成

### 功能说明

上传单个 2D 工艺图纸，AI 自动提取零件特征并生成加工工艺规程。

### 完整流程

```
① 上传图纸（PDF/PNG/JPG）
   ↓
② AI 自动特征提取（VLM 视觉分析）
   ↓
③ YOLO 自动检测标注（倒角、螺纹孔、圆孔）
   ↓
④ 人工审阅特征（表格化展示，支持原位编辑）
   ↓
⑤ 工艺规程生成（RAG 检索 + LLM 生成）
   ↓
⑥ 打字机动画逐行输出
   ↓
⑦ 导出 PDF / 入库
```

### 界面布局

- **左侧：** 图纸预览（支持多页翻页、缩放、全屏）
- **右侧：** 特征审阅 Tab + 工艺规程 Tab
- **顶部：** 统一进度条 + 阶段提示（呼吸灯动画）

> **截图位置：** 插入工艺生成相关截图（上传后、审阅中、输出完成）

## P8 — 标注工具

### 功能说明

基于 SVG 的矢量矩形标注工具，用于在 2D 图纸上标记工艺特征区域。

### 核心特性

| 特性 | 说明 |
|------|------|
| YOLO 自动检测 | AI 自动识别倒角、螺纹孔、圆孔 |
| 人工标注 | 鼠标拖拽绘制矩形框，右键删除 |
| 标签系统 | 内建 3 类标签 + 自定义标签 |
| 多页支持 | PDF 多页独立标注，切换自动保存 |
| 缩放适配 | Ctrl+滚轮缩放，适应视口/100% |
| 持久化 | 自动保存到服务端，页面关闭兜底 |
| 导出 | 标注数据导出为 ZIP |

### 标签类型

| 标签 | 颜色 | 说明 |
|------|------|------|
| 倒角 | 🟡 #f59e0b | chamfer |
| 螺纹孔 | 🟣 #6366f1 | threaded_hole |
| 圆孔 | 🟢 #10b981 | circle_hole |
| 自定义 | 循环色池 | 用户自定义标签 |

### 技术亮点

- 所有标注存储图片自然坐标，缩放不影响精度
- 标签常驻显示（未选中半透明，选中高亮）
- 标注汇总卡片实时统计各类型数量

## P11 — AI 核心能力

### VLM 视觉特征提取

- 输入：2D 工艺图纸（PDF/PNG/JPG）
- 输出：结构化特征报告
  - 尺寸公差
  - 表面粗糙度
  - 形位公差
  - 材料信息
  - 加工要求

### RAG 检索增强生成

- 知识库中检索相似工艺记录
- 结合 AI 特征报告和检索结果
- LLM 生成结构化工艺规程
- 输出格式：`工序号 @ 工种 @ 工序内容`

### 特征缓存机制

- 按文件 hash 判断是否为同一份图纸
- 开启后跳过 VLM 特征提取，直接返回上次结果
- 加速重复上传场景的响应速度

### 流式输出

- SSE 长连接实时推送工艺规程文本
- 打字机引擎逐行逐字符输出
- 中文/标点/数字使用不同延迟模拟真人节奏
- 支持中途编辑和实时预览
