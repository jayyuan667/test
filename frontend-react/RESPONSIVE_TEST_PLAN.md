## 测试工具

### 开发时断点调试
在浏览器控制台执行：
```js
document.documentElement.classList.add('debug-responsive')
```

## 测试用例

### TC-01: 侧栏响应式
**目标：** 侧栏在不同宽度下正确折叠/展开

| 步骤 | 预期结果 |
|------|----------|
| 1. 窗口 ≥1024px，刷新页面 | 侧栏展开，显示图标+文字 |
| 2. 窗口 <1024px，刷新页面 | 侧栏自动折叠，仅显示图标 |
| 3. 展开状态，拖拽窗口到 <1024px | 侧栏自动折叠 |
| 4. 折叠状态，点击折叠按钮 | 侧栏展开（覆盖自动折叠） |
| 5. 375px 宽度 | 侧栏折叠（72px），内容区占满剩余空间 |

**检查点：**
- [ ] 侧栏折叠后内容区不出现水平滚动条
- [ ] 折叠动画流畅（0.3s cubic-bezier）
- [ ] 导航项在折叠态居中显示图标

---

### TC-02: GeneratePage 空状态布局
**目标：** 空状态两栏等高，宽度统一

| 步骤 | 预期结果 |
|------|----------|
| 1. 1920×1080，空状态 | pageFrame max-w-[1360px]，两卡等高 |
| 2. 1366×768，空状态 | pageFrame 自适应，两卡等高 |
| 3. 768×1024（iPad竖屏） | 单列布局，卡片全宽 |
| 4. 375×667（手机） | 单列布局，卡片全宽，无水平溢出 |

**检查点：**
- [ ] toolbar/HUD/tab bar/workbench 宽度一致
- [ ] 左右卡片高度差 = 0
- [ ] 上传区 dropzone 居中显示
- [ ] 按钮文字不截断

---

### TC-03: GeneratePage 生成态布局

### TC-05: DbPage 三栏布局
**目标：** 数据库页筛选/列表/详情三栏响应式

| 步骤 | 预期结果 |
|------|----------|
| 1. ≥1024px，列表态 | 筛选面板(220px) + 记录列表(flex-1) |

| 3. <1024px，列表态 | 筛选面板隐藏，有"筛选"按钮展开浮层 |
| 4. <1024px，详情态 | 列表隐藏，详情全宽，有"返回列表"按钮 |
| 5. 375px，详情态 | 详情全宽，表格可滚动 |

**检查点：**
- [ ] 筛选浮层在移动端正确弹出/关闭
- [ ] "返回列表"按钮在小屏幕可见
- [ ] 记录卡片文字不溢出
- [ ] 快照弹窗在移动端图片和详情上下排列

## 执行方式

### 手动测试
1. 启动开发服务器：`cd frontend && npm run dev`
2. 打开 Chrome DevTools → 切换设备模拟器
3. 按分辨率矩阵逐个测试
4. 对照检查点逐项验证
5. 开启断点调试：`document.documentElement.classList.add('debug-responsive')`

### 自动化测试（待配置 Playwright）
```bash
npm install -D @playwright/test
npx playwright test responsive.spec.ts
```
